Quem Pode Participar

Abaixo estão os critérios para ingresso no programa, conforme legislação vigente.

Grupos Aptos a Participar

  • Estudantes de graduação — regularmente matriculados em instituições de ensino superior.
  • Estudantes de ensino médio — a partir do 1º ano.
  • Jovem aprendiz — idade mínima de 14 anos, conforme Lei nº 10.097/2000.

É proibido qualquer trabalho para menores de 16 anos, salvo na condição de aprendiz.

Documentos Necessários

  • Documento de identificação (RG ou CNH)
  • CPF
  • Comprovante de matrícula ou declaração escolar
  • Comprovante de residência

Requisitos Adicionais

  • Manter matrícula ativa durante toda a participação.
  • Estar dentro da faixa etária permitida para cada modalidade.
  • Atualizar os dados cadastrais sempre que necessário.
